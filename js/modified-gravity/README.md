# Six Polarization Modes（Modified Gravity）

研究分类、路径和论文列表仍为 Modified Gravity。动画标题为 **Six Polarization Modes**，标题位置和字号沿用原系列 CSS，不随本轮模式符号的放大而改变。

动画采用原生 ES modules + Canvas 2D。六个曲线小面板不需要三维场景，因此本组件不加载 Three.js；前两个组件仍使用原有本地 Three.js r180/WebGL2/ShaderMaterial。没有新框架、CDN、依赖或交互控件。

## 运行与导出

- Jekyll：启动现有本地预览，访问 `/research#modified-gravity`。
- 独立入口：`/js/modified-gravity/index.html`，必须通过 HTTP 服务访问，不直接双击 HTML。
- 在本目录执行 `npm test`、`npm run dev`、`npm run build`、`npm run preview`。
- 继续复用 `../agn-triple/scripts`；`--modified-gravity` 选择本组件，默认端口 4174。
- build 同时导出三个组件到 `D:\GitHub\no use\agn-triple-build`；保留原默认 AGN 首页和 Waveform Modeling 的命令行为。
- `.npmrc` 禁止生成锁文件，将缓存放在 no use。项目没有待安装的依赖。

下方严格只有两条曲线：

```text
φ(t) = 2π f₀ t + φ₀
GR(t) = A₀ cos φ(t)
modified(t) = GR(t) + A₁ cos(0.5 φ(t) + φ₁)
```

第二项从同一个 φ(t) 推导，而非独立定义时间相位。当前 φ₀=−4.96、φ₁=0.74 rad，A₀=1、A₁=0.60。附加分量的周期是 GR 的两倍，不是两倍频率。
所有上方面板只读取 GR 主频和相位，绝不将附加半频项加入模式形变。
这已按最新补充替代初版 inspiral/chirp 方案；旧 chirp 驱动和参数已删除。没有 merger/ringdown，也没有第三条信号曲线。

频率与应变是归一化展示量；双频叠加是给定的图示规则，不是论文数值复现、探测器输出、ppE 拟合模板或某个修改引力模型的定量预测。

## 极化基与坐标核对

六个基采用 [Nishizawa et al. (2009), Eq. (1)](https://arxiv.org/abs/0903.0528)，满足对称性与 `E_A:E_B=2δ_AB`。传播方向统一为 +z。
显示几何为 `r' = r + ε(t) E_A r`；ε 已为识别度放大并吸收归一化系数，不是实际天文应变。
每个面板是单独激发一个基的示意，不意味着某个源同时存在六种模式；GR 本身只含两个张量模式。

| 模式 | 面内轴 | 正方向/第三轴 |
|---|---|---|
| h₊、h×、h_b | x / y | x 右、y 上，+z 朝观察者（⊙） |
| hₓ、h_l | x / z | x 右、z 上，+y 背离观察者（⊗） |
| h_y | y / z | y 左、z 上，+x 背离观察者（⊗） |

h_y 从相反侧观察 yz 平面，产生镜像外观；没有人为反转极化基或额外改变振荡相位。
点/叉表示第三个轴相对观察者的方向；侧视面板中的正 z 箭头表示传播方向。各视图均通过右手系检查。
纵向模式必须在含 z 的平面展示，不能在 xy 横截面上伪装成呼吸模式。
