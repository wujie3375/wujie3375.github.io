# Hierarchical Triple

用于 Jekyll 研究页 Moving Sources 分类的非交互动画。保留原生 ES modules、本地 Three.js r180、WebGL2、正交相机、ShaderMaterial 和两条独立 Kepler 轨道；没有 Vite、CDN、新依赖、交互控件或重后处理。

## 运行与静态导出

网站入口为 `/research#moving-sources`，独立入口为 `/js/agn-triple/index.html`。照常启动现有 Jekyll 本地预览即可。

在本目录运行：

```powershell
npm test
npm run dev
npm run build
npm run preview
```

dev/preview 默认使用 127.0.0.1:4174，先结束 dev 再运行 preview。环境变量 `PORT` 可更换端口。
四个项目共用现有 Node 静态服务和导出脚本，build 同时导出四个动画及本地 Three.js，默认输出位于 `D:\GitHub\no use\agn-triple-build`；`AGN_TRIPLE_BUILD_DIR` 可覆盖输出目录。
静态导出是可直接部署的网页资源，不是视频编码。导出的入口和网站嵌入使用同一 4:3 运行时与清晰度预算。
没有待安装的 npm 依赖。npm 不在 PATH 的验收环境使用 no use 中已有的官方 npm CLI，不安装全局工具。

## GW 历史传播与软体积显示

`GWEmissionManager` 从当前 Kepler 结果提取不包裹真近点角，采用 `phiGW=2*phiInner`。
按相位阈值二分求解子帧发射时刻，保存冻结的发射时间、质心原点、方向和强度；已发射原点不再跟随当前质心。

- 视觉抽样间隔 2π，每内轨道两次，相位仍为 2φ；减速后不堆积前沿。它与物理 GW 相位、视觉传播速度是不同概念。
- 世界坐标半径为 `gwVisualSpeed × (tNow−tEmit)`，传播速度 2.2（较前轮降低 45%），最大半径 2.5，池上限三个。
- 新波前平滑淡入，外侧加速淡出并回收；当前 alpha 0.48，不无限增加对象。
- shader 删除 Fresnel 硬边和两条大圆经线。支持几何改为与 XY 吸积盘平行的软面，八点视线密度积分保留宽缓透明体积，另加软 Gaussian 亮波前（相对半径 0.84、当前宽度 0.082），支撑几何边缘仍不可见。
- 不画线框球、辅助圆环或贴在盘面的二维水波；不使用昂贵的全场景光线追踪。

这只是辐射来源、相位与历史传播的示意，不是等应变面、完整极化张量场或真实辐射转移。中央剪影遮罩只是构图辅助，不代表计算了 GW 吸收或 GR 光线追踪；背景星点不再按 GW 变化。
管理器支持一个可选的源采样回调，供 CBC 复用同一对象池；AGN 默认路径仍读取原 Kepler 求解器。

### Doppler 符号、单位和积分

```text
N = normalize(cameraPosition)（可用 observerDirection 显式覆盖）
v_los = dot(existing Kepler outer.velocity, N)
beta = v_los / c_AU_per_year
f_physical ≈ f_source × (1 + beta)
f_visual = f_source × (1 + dopplerVisualBoost × beta)
Phi_visual(t) = Phi0 + 2π integral(f_visual dt)
h_visual(t) = A(t) cos(Phi_visual(t))
```

N 指向远场观察者，当前约 [0.358399,−0.806397,0.470398]。正 v_los 表示朝向观察者，因此蓝移；负值红移。速度直接使用原 Kepler 输出的 AU/year，不乘空间放大或播放倍率；光速由 SI 常数转换到 AU/Julian-year。

当前原始 max|beta|≈0.005867。显示增强由目标 0.34 与采样极值自动推导并留 1% 安全余量，`dopplerVisualBoost≈57.38`；并非手写独立正弦，实际显示频率约 1.17～2.43 展示周期/秒，始终为正。

本征频率来自原内轨道的角动量/r²，即现有真近点角的两倍导数；默认 intrinsicChirpRate=0，采用早期近单频、无辐射反作用的极限，不把单独加速波形误当成内轨道已经收缩。振幅只随近单频的微小变化作轻微平滑调整，不含 merger/ringdown。

相位用 4096 个区间的 Simpson 积分和带导数的 Hermite 插值，不使用 `cos(2π f(t) t)`。返回值同时保留未经增强的 `physicalObserved` 与显示的 `observed`，防止把增强后的结果当成真实预测。

只有一条金色曲线，无 GR 参考、坐标轴、基线或公式标签。与天体、外轨道速度及已有波前共用 elapsed 播放时间；已有内外独立年/播放秒映射保持原样。波形首次 0.35 秒淡入，周期末 0.55 秒淡出后重置，避免相位接缝。

新增 `src/waveform/dopplerModel.js`、`createDopplerWaveform.js` 和 `tests/doppler.test.js`；修改 `src/main.js`、config、盘 shader/绑定、静态星点遮罩、独立入口/style 和研究 include 的透明波形层。`physics/kepler.js` 与 `animation/systemState.js` 的校验值均未改变。
