研究分类仍为 **Waveform Modeling**，页面路径、文章列表和正文不变。只有动画左上角文本改为 **Compact Binary Coalescence**，标题的原位置、字号、颜色和边距不变。

保留原生 ES modules、本地 Three.js r180/WebGL2、自定义 ShaderMaterial 和下方单条 Canvas 2D waveform。没有新增框架、依赖、CDN、交互控件或重后处理。

## 运行

Jekyll 入口 `/research#waveform-modeling`，独立入口 `/js/waveform-modeling/index.html`。

在本目录执行 `npm test`、`npm run dev`、`npm run build`、`npm run preview`，仍复用原 AGN 的 Node 服务与静态导出脚本。默认端口 4174；build 同时导出四个动画到 `D:\GitHub\no use\agn-triple-build`。发布构建说明见 `../agn-triple/README.md`，esbuild 只用于构建，不增加浏览器运行依赖。
没有视频编码步骤；静态入口使用与网站相同的 4:3 和分辨率配置。

## 主运动与波形保持原模型

- 质量比 30:20 通过质量加权位置保持共同质心；大黑洞的轨道偏移较小。
- Inspiral 使用低阶 chirp 形态 f∝(tc−t)^(-3/8)，A∝f^(2/3)，分离距离∝f^(-2/3)。
- Merger 仍用一阶连续的 Hermite 匹配；相位来自积分频率和 Hermite 相位插值，轨道相位为 GW 相位的一半。
- 9.7 秒融合完成、峰值 strain=+1。Ringdown 频率趋于稳定，振幅平滑阻尼衰减。
- 下方只有一条从左向右逐步绘制的路径，包含完整 inspiral/merger/ringdown；glow 是同一路径的阴影。
- 最终黑洞本体保持黑色，边缘 halo 短暂增强后稳定；轻微形变来自同一振铃相位。

没有改写 `animation/coalescence.js` 主运动公式。增加绕转主要来自延长 inspiral 的时间分配，不是极端提高角速度。
这些是展示单位和归一化模型，不是 LALSuite/NR 校准模板；没有自旋、进动、高次模式、探测器响应或可用于参数估计的绝对应变。

## 持续 GW 辐射与余波

新增 `animation/gwSource.js` 读取同一个 chirp 相位、振幅和质量加权质心，接入原 AGN 的历史发射管理器与软体积对象池。

- Inspiral 持续低强度辐射，merger 最强，ringdown 发射强度跟随阻尼振幅减弱。
- 本轮每个 GW 周期一次（相位间隔 2π），初始事件对齐 0 秒；随后严格跟随同一相位，频率升高时发射更快。
- 当前历史池容量上限十二个，覆盖两秒内每周期一次的发射；传播速度 1.8 世界单位/播放秒，最远 3.6，2.7～3.6 按半径平滑淡出，不按发射周期提前回收。
- 每个事件保存冻结的历史发射原点。CBC 质心固定，因此这些原点自然重合；不会人为挪动质心制造假运动。
- 波前 group 位于 scene 根层，不绑定当前双星或最终黑洞。
- 保留单面球形支持几何上的软密度积分，新增较清楚的软亮波前，不画几何网格或经线；下方渐隐区域保护波形清晰度。
- Merger 余波复用同一软体积 shader 和几何，而非平面水波图标；暖金余波与冷白连续辐射相协调。
- 可关闭持续辐射而不破坏最终黑洞或单独的并合余波。

这仍是相位/传播示意，不是实际引力波的发光气体、完整张量场或真实辐射转移。

## 当前版本：更明确的峰后显示阻尼（四动画精修）

原历史前沿保留发射强度且ageFade较慢，在merger后仍有较高的叠层亮度。本轮在原亮度预算后叠加可视化阻尼：

```text
visibility = 0.06 + 0.94 exp(−max(0,t−mergerPeak−0.10)/0.65)
```

峰值时因子为1，峰后0.8秒约0.38、1.55秒约0.16，最终趋于6%弱残影，再由原波龄/距离/边缘淡出自然消失。它是科研网页展示的亮度强调，不是真实迟滞辐射能量计算；不直接乘当前已接近零的waveform包络把历史波彻底消灭。
